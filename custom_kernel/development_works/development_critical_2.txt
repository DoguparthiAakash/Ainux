====================================================================
KERNEL / OS COMMANDS WITH USAGE — STABILITY-FIRST (BSD-PLUS)
====================================================================

------------------------------------------------------------
SECTION 1 — PROCESS & TASK CONTROL (USED ALL DAY)
------------------------------------------------------------

ps        : Display currently running processes and their states
top       : Real-time view of CPU, memory usage, and task scheduling
htop      : Enhanced interactive process viewer
kill      : Send a signal (terminate, stop, continue) to a process
killall   : Send signals to processes by name
nice      : Start a process with modified scheduling priority
renice    : Change priority of an already running process
bg        : Resume a stopped job in background
fg        : Resume a stopped job in foreground
jobs      : List background and stopped jobs in current shell
time      : Measure execution time of a command
watch     : Execute a command repeatedly at fixed intervals

------------------------------------------------------------
SECTION 2 — FILESYSTEM & FILE OPERATIONS (EVERY PROGRAM)
------------------------------------------------------------

ls        : List files and directories
tree      : Display directory hierarchy in tree format
stat      : Show detailed file or filesystem metadata
file      : Identify file type
cat       : Display file contents
less      : Paginated file viewer
more      : Basic paginated file viewer
cp        : Copy files or directories
mv        : Move or rename files/directories
rm        : Delete files or directories
mkdir     : Create directories
rmdir     : Remove empty directories
touch     : Create empty files or update timestamps
chmod     : Change file permissions
chown     : Change file ownership
find      : Search for files in directory hierarchy
du        : Display disk usage of files/directories
df        : Show filesystem disk space usage
sync      : Flush filesystem buffers to disk

------------------------------------------------------------
SECTION 3 — MEMORY & RESOURCE MONITORING
------------------------------------------------------------

free      : Display system memory usage
vmstat    : Show memory, paging, and CPU statistics
pmap      : Display memory map of a process
ulimit    : Set or view resource limits for processes
top       : Monitor memory pressure and CPU usage in real time

------------------------------------------------------------
SECTION 4 — DEVICE, DISK & HARDWARE CONTROL
------------------------------------------------------------

lsblk     : List block storage devices
mount     : Attach a filesystem to the directory tree
umount    : Detach a mounted filesystem
blkid     : Display block device attributes (UUID, type)
dmesg     : Show kernel message buffer
lspci     : List PCI devices
lsusb     : List USB devices
hwinfo    : Detailed hardware information

------------------------------------------------------------
SECTION 5 — INTERPROCESS COMMUNICATION & SYSTEM STATUS
------------------------------------------------------------

ipcs      : Display System V IPC resources (shared memory, semaphores)
ipcrm     : Remove IPC resources
ss        : Display socket statistics
netstat   : Show network connections and routing tables
ping      : Test network reachability

------------------------------------------------------------
SECTION 6 — NETWORKING (EVERY CONNECTED SYSTEM)
------------------------------------------------------------

ip        : Configure and display network interfaces and routes
ifconfig  : Legacy tool to configure network interfaces
ping      : Check host reachability and latency
traceroute: Display route packets take to a network host
curl      : Transfer data from or to a server
wget      : Download files from the web
ssh       : Secure remote shell access
scp       : Secure file copy over SSH
nc        : Network debugging and data transfer tool

------------------------------------------------------------
SECTION 7 — USER, AUTHENTICATION & PERMISSIONS
------------------------------------------------------------

id        : Display user and group identity
whoami   : Display current user name
login     : Start a user session
logout    : End current user session
su        : Switch user identity
sudo      : Execute command as another user (usually root)
passwd    : Change user password
groups    : Show group memberships

------------------------------------------------------------
SECTION 8 — TIME, TIMERS & SCHEDULING
------------------------------------------------------------

date      : Display or set system date and time
uptime    : Show how long the system has been running
sleep     : Delay execution for a specified time
watch     : Repeatedly run a command at intervals
time      : Measure execution time of a command
cron      : Schedule recurring background jobs
at        : Schedule one-time jobs

------------------------------------------------------------
SECTION 9 — SYSTEM CONTROL & POWER MANAGEMENT
------------------------------------------------------------

reboot    : Restart the system
shutdown  : Power off or reboot the system safely
poweroff  : Immediately power off the system
halt      : Stop all CPU activity
uptime    : Display system runtime duration
watchdog  : Monitor system health and trigger recovery actions

------------------------------------------------------------
SECTION 10 — LOGGING, DEBUGGING & DIAGNOSTICS
------------------------------------------------------------

dmesg     : Display kernel logs
journalctl: Query system logs
strace    : Trace system calls of a process
ltrace    : Trace library calls of a process
perf      : Performance analysis and profiling tool
vmstat    : Report virtual memory statistics

------------------------------------------------------------
SECTION 11 — SECURITY & ISOLATION
------------------------------------------------------------

getenforce: Display SELinux enforcement mode
setenforce: Change SELinux enforcement mode
auditctl  : Configure auditing rules
ausearch  : Search audit logs

------------------------------------------------------------
SECTION 12 — BOOT, INIT & SERVICE MANAGEMENT
------------------------------------------------------------

init      : Start the first user-space process
systemctl: Control system and service manager
service   : Manage system services
loginctl  : Manage user login sessions

------------------------------------------------------------
SECTION 13 — CORE EVERYDAY COMMANDS (MOST FREQUENT)
------------------------------------------------------------

ls        : Inspect filesystem
ps        : Inspect running processes
top       : Inspect system load
kill      : Control misbehaving processes
mount     : Manage filesystems
df        : Monitor disk space
free      : Monitor memory
dmesg     : Inspect kernel state
reboot    : Recover from fatal conditions
