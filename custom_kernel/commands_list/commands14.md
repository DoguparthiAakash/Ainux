
| Command          | Purpose / Use Case                                  | Example                       |
| ---------------- | --------------------------------------------------- | ----------------------------- |
| **awk**    | Pattern scanning + text processing language         | `awk '{print $1}' file.txt` |
| **aspell** | Spell checker for text files                        | `aspell check file.txt`     |
| **banner** | Prints large ASCII text banner                      | `banner Hello`              |
| **bc**     | Command-line calculator                             | `echo "5+10" \| bc`          |
| **col**    | Filters reverse line feeds / cleans text formatting | `col < file.txt`            |
| **colcrt** | Formats text for CRT terminal display               | `colcrt file.txt`           |
| **colrm**  | Removes selected columns from text                  | `colrm 1 5 < file.txt`      |
| **column** | Formats text into aligned columns                   | `column -t file.txt`        |
| **dc**     | Reverse Polish Notation calculator                  | `dc`                        |
| **egrep**  | Extended regular expression grep (`grep -E`)      | `egrep "cat                   |
| **fgrep**  | Fixed string grep (`grep -F`)                     | `fgrep "hello" file.txt`    |
| **fmt**    | Simple text formatter/wrapper                       | `fmt file.txt`              |
| **grep**   | Search text patterns                                | `grep "error" log.txt`      |
| **sdiff**  | Side-by-side file comparison                        | `sdiff file1 file2`         |
| **sed**    | Stream editor (find/replace/edit text)              | `sed 's/old/new/' file.txt` |
| **tr**     | Translate/delete characters                         | `tr a-z A-Z`                |
