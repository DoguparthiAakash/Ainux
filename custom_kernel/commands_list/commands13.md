
| Command          | Purpose / Use Case                               | Example                         |
| ---------------- | ------------------------------------------------ | ------------------------------- |
| **ar**     | Creates/manages static library archives (`.a`) | `ar rcs libtest.a file.o`     |
| **bzcmp**  | Compare two bzip2 compressed files               | `bzcmp file1.bz2 file2.bz2`   |
| **bzdiff** | Show differences between`.bz2`files            | `bzdiff old.bz2 new.bz2`      |
| **bzgrep** | Search text inside`.bz2`compressed files       | `bzgrep "error" log.bz2`      |
| **bzip2**  | Compress files using bzip2 algorithm             | `bzip2 file.txt`              |
| **bzless** | View`.bz2`file content page by page            | `bzless logs.bz2`             |
| **bzmore** | Similar to`more`but for`.bz2`files           | `bzmore logs.bz2`             |
| **gunzip** | Decompress`.gz`files                           | `gunzip backup.gz`            |
| **gzip**   | Compress files using gzip                        | `gzip file.txt`               |
| **gzexe**  | Compress executable files                        | `gzexe script.sh`             |
| **zip**    | Compress files into`.zip`archive               | `zip files.zip a.txt b.txt`   |
| **zdiff**  | Compare gzip-compressed files                    | `zdiff old.gz new.gz`         |
| **zgrep**  | Search text inside`.gz`compressed files        | `zgrep "error" server.log.gz` |
