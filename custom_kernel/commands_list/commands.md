| Command           | Full Use / Purpose                                   | Example                               |
| ----------------- | ---------------------------------------------------- | ------------------------------------- |
| **ls**      | Lists files and directories in the current directory | `ls`                                |
| **cp**      | Copies files or directories                          | `cp file1.txt file2.txt`            |
| **touch**   | Creates a new empty file or updates timestamp        | `touch notes.txt`                   |
| **man**     | Shows manual/help page for a command                 | `man ls`                            |
| **sort**    | Sorts lines in a file alphabetically/numerically     | `sort names.txt`                    |
| **pwd**     | Prints current working directory                     | `pwd`                               |
| **mv**      | Moves or renames files/directories                   | `mv old.txt new.txt`                |
| **ln**      | Creates links (hard link or symbolic link)           | `ln -s file shortcut`               |
| **grep**    | Searches text patterns inside files                  | `grep "hello" file.txt`             |
| **cal**     | Displays calendar in terminal                        | `cal`                               |
| **mkdir**   | Creates a new directory                              | `mkdir project`                     |
| **rm**      | Deletes files or directories                         | `rm file.txt`                       |
| **cat**     | Displays file content                                | `cat notes.txt`                     |
| **echo**    | Prints text or variables to terminal                 | `echo "Hello"`                      |
| **whereis** | Finds location of command binaries/source/manual     | `whereis python`                    |
| **cd**      | Changes current directory                            | `cd Documents`                      |
| **uname**   | Shows system/kernel information                      | `uname -a`                          |
| **clear**   | Clears terminal screen                               | `clear`                             |
| **wget**    | Downloads files from internet using URL              | `wget https://example.com/file.zip` |
| **df**      | Shows disk space usage of file systems               | `df -h`                             |
| **rmdir**   | Removes empty directories                            | `rmdir folder`                      |
| **locate**  | Finds files by name quickly using database           | `locate file.txt`                   |
| **ps**      | Shows currently running processes                    | `ps aux`                            |
| **whoami**  | Displays current logged-in username                  | `whoami`                            |
| **wc**      | Counts lines, words, characters in a file            | `wc file.txt`                       |
