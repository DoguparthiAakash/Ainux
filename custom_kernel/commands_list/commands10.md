
| Command                  | Purpose / Use Case                               | Example                         |
| ------------------------ | ------------------------------------------------ | ------------------------------- |
| **acpi**           | Shows battery, thermal, and AC power information | `acpi -V`                     |
| **acpi_available** | Checks whether ACPI support is available         | `acpi_available`              |
| **acpid**          | ACPI daemon that handles power events            | `sudo systemctl status acpid` |
| **arch**           | Displays CPU architecture                        | `arch`                        |
| **dmesg**          | Shows kernel boot and hardware messages          | `dmesg`                       |
| **dmidecode**      | Shows BIOS and hardware information              | `sudo dmidecode`              |
| **dstat**          | Real-time system resource statistics             | `dstat`                       |
| **free**           | Shows RAM and swap usage                         | `free -h`                     |
| **hdparm**         | Get/set hard disk parameters                     | `sudo hdparm -I /dev/sda`     |
| **hwclock**        | Shows/sets hardware clock (BIOS clock)           | `hwclock`                     |
| **iostat**         | CPU + disk I/O statistics                        | `iostat`                      |
| **iotop**          | Shows disk I/O usage by processes                | `sudo iotop`                  |
| **lsusb**          | Lists connected USB devices                      | `lsusb`                       |
| **lshw**           | Detailed hardware information                    | `sudo lshw`                   |
| **uname**          | Shows kernel/system information                  | `uname -a`                    |
