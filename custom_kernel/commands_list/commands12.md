
| Command                | What it is                                                      | Best use                                    |
| ---------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| **`apt`**      | Modern high-level package manager                               | Everyday usage (recommended for humans)     |
| **`apt-get`**  | Older low-level package management command                      | Scripts, automation, backward compatibility |
| **`aptitude`** | Advanced package manager with dependency resolver + terminal UI | Complex dependency management               |
