
| Command          | Purpose / Use Case                                             | Example                       |
| ---------------- | -------------------------------------------------------------- | ----------------------------- |
| **chmod**  | Changes file or directory permissions (read, write, execute)   | `chmod 755 script.sh`       |
| **chattr** | Changes special file attributes (immutable, append-only, etc.) | `chattr +i file.txt`        |
| **chown**  | Changes file owner (user ownership)                            | `chown user file.txt`       |
| **chgrp**  | Changes file group ownership                                   | `chgrp developers file.txt` |
