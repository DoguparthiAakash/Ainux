
| Command           | Purpose / Use Case                                    | Example                                         |
| ----------------- | ----------------------------------------------------- | ----------------------------------------------- |
| **cd**      | Change current directory                              | `cd Documents`                                |
| **du**      | Shows disk usage of files/directories                 | `du -sh folder/`                              |
| **mount**   | Mount a filesystem/device so Linux can access it      | `mount /dev/sdb1 /mnt`                        |
| **dir**     | Lists directory contents (similar to`ls`)           | `dir`                                         |
| **find**    | Searches for files/directories based on conditions    | `find . -name "*.txt"`                        |
| **pwd**     | Prints current working directory                      | `pwd`                                         |
| **dirname** | Extracts directory path from full file path           | `dirname /home/user/file.txt`→`/home/user` |
| **lsblk**   | Lists block storage devices (disks, USBs, partitions) | `lsblk`                                       |
| **rmdir**   | Removes empty directory                               | `rmdir temp`                                  |
| **dirs**    | Shows directory stack used with`pushd/popd`         | `dirs`                                        |
| **mkdir**   | Creates a new directory                               | `mkdir project`                               |
| **tree**    | Displays directories/files in tree structure          | `tree`                                        |
