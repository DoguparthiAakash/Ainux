
| Command          | Purpose / Use Case                            | Example             |
| ---------------- | --------------------------------------------- | ------------------- |
| **md5sum** | Generates MD5 hash/checksum of a file         | `md5sum file.iso` |
| **cksum**  | Generates CRC checksum + file size            | `cksum file.txt`  |
| **sum**    | Generates basic checksum (older Unix utility) | `sum file.txt`    |
